# PirateShield – First Phase

**Author:** Darin Duong  
**Area of Focus:** Identity and User Behavior  
**Timeframe:** January 21 – January 31, 2026  
**Purpose:** Develop the foundations, rules, and architecture before implementation.

---

## Objectives

- Understand login behavior in K-12 environments.
- Be able to draft rules for identity-related security events.

---

## Tasks

1. Study login behavior in K-12 environments (Google Workspace, Canvas, School WiFi authentication, etc.).
2. List identity-related events such as login success, login failure, login time, location/IP, and associated device.
3. Draft identity anomaly rules, including:
   - Off-hours login
   - Burst of failed logins
   - Login from new IP or location
